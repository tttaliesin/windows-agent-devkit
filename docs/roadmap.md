P0 전체의 관리자 활성화·실제 SDK 선택·Compose·context 등의 완성은 남아 있습니다.
실행 방법과 제한은 [진단 CLI 사용법](diagnostic-cli.md)에 기록합니다.
이번 실행 검증 결과는 [첫 CLI 검증 기록](verification.md)에 기록합니다.
